# Small Site — Team Workflow Demo

## Goal

Create a small static website demonstrating the team-workflow pipeline.

## Scope

A single-page personal landing site:

- `index.html` — landing page with hero, about, and contact sections
- `styles.css` — minimal, clean styling (system fonts, light/dark friendly)
- `README.md` — explains what the site is and how to view it locally

## Content

- **Hero**: name "Nikos Kostopoulos", short tagline ("Software engineer, builder of things").
- **About**: 2–3 sentences placeholder bio.
- **Contact**: mailto link to `nikos@papergo.io`.

## Constraints

- No build step. Plain HTML/CSS — open `index.html` directly in a browser.
- No external CDNs, no JS frameworks.
- Mobile-responsive (single column at narrow widths).
- Semantic HTML5 (header, main, section, footer).

## Acceptance

- Opening `index.html` in a browser shows the three sections.
- `README.md` documents how to view and what's in the repo.
